# Synapse

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Students learning AI and preparing for AI engineer interviews. Their information is spread across articles, roadmaps, PDFs, images, and videos. They use a notebook for sustained writing, explanation, and revision.

## Product Purpose

Connect knowledge in a local notebook and practice retrieving it. A saved note does not establish understanding. Collected, explained, and practiced are distinct states.

## Operating Context

React and TypeScript browser UI with a local Windows Express companion. Markdown files in a local vault are canonical. Optional Vercel frontend connects to the running companion through explicit pairing. Ollama is the configured local AI provider. Hermes supplies the existing Telegram voice pipeline and explicitly approved delivery.

## Capabilities and Constraints

Normal writing first. Slash commands and contextual formatting add blocks. Users create and approve connections. One canonical concept may belong to a page hierarchy and have several cross-links. Diagram suggestions require review before insertion. Definition variants are unlimited and optionally labelled. Images, tables, tasks, code, and editable transparent drawings live between paragraphs. Sharing uses scoped access links. The local service must run for the hosted companion to access the vault.

## Brand Commitments

Synapse retains its sage and ink identity. The user confirmed refinement of that identity on 2026-10-27. Diagrams use Diagram Design's stock editorial style, separately confirmed by the user. Never use em dashes in original interface copy, generated text, or documentation.

## Product Principles

- Writing and recall take priority over collecting.
- Connections express the student's reasoning.
- Show evidence and uncertainty without inventing mastery.
- Keep files portable and preserve prior versions.
- Reveal complexity when needed.

## Evidence on Hand

The real local vault, source code, tests, and recorded runtime checks. No testimonials, invented learning statistics, or cloud persistence claims.
