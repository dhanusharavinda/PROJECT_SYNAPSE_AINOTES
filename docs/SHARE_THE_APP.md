# Send Synapse to someone

Send this link: https://github.com/dhanusharavinda/PROJECT_SYNAPSE_AINOTES/releases/latest

They download and run `Synapse-Setup-<version>.exe` on a Windows x64 computer. You can send that same installer file directly instead. An APK is an Android package; Synapse currently ships as a Windows app.

On first launch they choose a folder for their own notebook. A fresh notebook starts empty. They can write, draw, link notes, use the graph, and practice without coding tools or an API key. AI features use their own configured provider, such as local Ollama or their own OpenAI key. Hermes audio needs their own Hermes setup.

Send only the installer or download link. Your vault and configuration files are not needed to install the app. Each person keeps separate notes and settings.

Synapse checks for published updates after opening and periodically while running. The user chooses Download, then Restart and update. They can also use Help > Check for updates. You do not need to send a new installer for every release.

The current build is unsigned, so Windows may show a SmartScreen warning. The app's code and release notes are available in the same repository.
