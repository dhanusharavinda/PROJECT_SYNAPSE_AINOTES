# PC keyboard and iPad stylus

Synapse 1.10.1 provides a focused notebook workspace for spacedesk. Open a page in the Windows app and enable **Canvas focus**. Stylus mode is enabled by default and can be changed under Settings in the tool wheel or All tools menu. These choices are remembered on this PC.

- **Canvas focus** fills the app window and keeps the page scrollable. It hides the surrounding panels and footer, keeps saving status visible, and shows compact tools with All notes and parent-note navigation. Press Escape or use Exit canvas focus to restore the surrounding interface.
- **Pen** draws. **Write** edits the main text or places a typing caret wherever you tap. Use the PC keyboard for typing. A blank tap does not save an object. Empty text drafts disappear when you leave them, and text objects are saved only once they contain text. Existing empty text objects are hidden and removed on the next canvas edit. Clearing a placed text object returns it to an unsaved caret, so you can start typing again.
- In Stylus mode with the tool wheel enabled, hold a pen still for about half a second to open it. Moving more than eight screen pixels cancels the hold and keeps drawing. Opening the wheel rolls back the temporary mark, so no dot is saved. The wheel stays open until dismissed or an action closes it. Turn off Tool wheel in Brush settings to prevent hold activation and use the compact All tools menu instead.
- The hold works with pen events and mouse-compatible stylus input. It does not require pressure sensitivity. Actual pressure changes stroke weight only when the input device and spacedesk transmit it. Pencil squeeze and Pencil hover are not implemented.
- Fingers pan while a drawing or selection tool is active. Use two fingers to pan and zoom. A pen takes priority over finger navigation, and unrelated palm events cannot cancel the pen gesture. In Write and Text modes, a single touch retains normal text interaction.
- The **Hand** tool only pans, regardless of pressure. The separate **Select** button selects objects with a dragged rectangle and lets you move selected objects. Use Delete to remove a selection. Pressure does not switch tools.
- Holding Space and dragging also pans when the canvas is focused. Space continues to type normally inside text editors. Middle mouse dragging and Ctrl+scroll zoom remain available. The toolbar has Zoom out, Zoom in and a percentage button to reset to 100%. Queued zoom updates are discarded once a drawing or navigation gesture starts.
- **All tools** opens the wheel when enabled, or a compact grouped menu when disabled. Both provide shapes, highlighters, insertion, font, theme and other secondary actions. The wheel stays open until an action, Escape, its close button, or an outside tap dismisses it. Its center stays fixed while categories expand.
- **Brush settings** combines color, pen size, the Tool wheel switch and an optional personal handwriting font importer. The main toolbar includes writing, Hand, Select, Pen, Eraser, quick Arrow styles, All tools, Delete, zoom, Brush settings, Undo, Redo and canvas focus.
- Ordinary page footer actions are collapsed under **Page actions**. They remain available outside Canvas focus.

Coalesced pointer samples feed a separate live ink canvas, so drawing previews do not rebuild every saved page object on each pointer move. Committed strokes remain editable vectors. Interrupted strokes keep captured ink, and background autosave does not end a held stroke. Canvas objects retain their logical coordinates at tablet viewport widths. Synapse still renders on Windows and spacedesk transports the display and input, so physical drawing latency and pressure behavior must be evaluated on the actual iPad. These changes do not establish parity with Procreate.

Regression coverage includes pen and mouse hold activation, moving strokes, no-dot rollback, pen reuse after dismissal, unrelated touch cancellation, hand panning, pen takeover from touch, and leaving Canvas focus. Frontend rendering was reviewed at iPad mini portrait and landscape sizes. Physical stylus acceptance remains for the owner.
