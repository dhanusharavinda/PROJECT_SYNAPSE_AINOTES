# Synapse 1.9.0

Notes now form a folded page tree in All notes and the sidebar. Expand a parent to reveal its subpages. Search includes matching children and their parents. Shared pages display an accessible breadcrumb path, and editors can create a subpage with New page or `/page`. New subpages inherit the parent's group, theme, and sharing access.

Drag the writing area's corner to set its width and height. Long text wraps at the new width without changing its font size. Placed text also reflows when resized; group resizing continues to scale its contents. These changes participate in undo and save with the note.

Shared saves retry temporary connection failures and active editing leases automatically. A retry after a lost acknowledgement reuses the original operation, so it cannot overwrite newer collaborator changes. A late close from an older relay connection no longer interrupts the replacement connection. Presence heartbeats avoid resending an unchanged page. Actual conflicting changes still preserve a draft for review.

The shared header now keeps a short save status and New page in view. Save, Share, and Slides are inside More actions. Draft recovery appears only when a change needs review, rather than presenting three recovery buttons for a temporary connection failure.

Update both PCs through Help > Check for updates, then restart. Refresh the tablet companion after the PC update.

Validation: 240 checks across 37 suites, TypeScript, production build, installer packaging, and browser checks of nested page creation, lineage, folded notes, and two-dimensional writing-area resizing. Two real collaboration service sessions were tested through repeated edits, a lost save acknowledgement, and typing during recovery. Physical two-PC interaction and native EXE launch were not retested. Simultaneous character merging within the same field is not supported; active field leases still apply.
