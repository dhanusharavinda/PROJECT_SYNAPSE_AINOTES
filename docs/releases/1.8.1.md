# Synapse 1.8.1

This update makes Practice more compact, keeps Settings within reach, and fixes diagram creation on shared pages.

- The green welcome now lasts four seconds by default, including its fade. Open notebook or Escape can skip it. Reduced motion removes movement while keeping the requested duration.
- The tool wheel uses a translucent glass surface. It fades shortly after the pointer leaves and closes when you click elsewhere, including on the canvas.
- Practice puts the note selector and Recall/Flashcards together. Answer boxes and extra settings stay collapsed until needed.
- Settings remains in the sidebar footer on small laptop displays. When the sidebar is closed, a Settings icon remains in the top bar.
- One Make a diagram command replaces the duplicate entries. Both /diagram and /flowchart find that action.
- Shared-page editors can generate and approve diagrams instead of seeing the unsupported canvas command message. Viewers cannot insert them.
- Paired tablets can request diagrams through the PC's configured AI. Keep Synapse open on the updated PC. Drafts become editable canvas objects only after Insert diagram, support undo, and are brought into view.
- Resource dump fetches available website preview images, alongside uploaded images and YouTube thumbnails. Missing or blocked previews use a quiet fallback. Previews do not run AI.

Update Windows through Help > Check for updates, or use the installer from this release. Reopen or refresh the tablet app to load the new web version. Existing notebook files stay in place.

Validation: 221 automated checks, production build, browser review at 1280 x 720, 1024 x 600 and 390 x 844, a successful local Ollama diagram request with a cached repeat, and a live website thumbnail fetch. Physical stylus behavior and native Windows launch were not retested in this pass.

Website previews depend on what the source exposes publicly. Some social posts require login or block previews. PDFs use a file preview placeholder. Tablet diagram generation requires a paired, online PC with an AI provider configured. AI Practice remains in the main notebook workspace.
