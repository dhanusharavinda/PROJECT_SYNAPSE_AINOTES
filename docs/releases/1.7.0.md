# Synapse 1.7.0

Use Ctrl+scroll to zoom around the cursor and hold the middle mouse button to pan. The percentage button resets zoom. Selected objects have drag, resize and rotation handles. Highlighter strokes sit underneath writing, retain their original colour and can be selected, moved, resized, rotated, erased or deleted. The arrow menu includes straight, curved, elbow and double-ended arrows.

Text formatting now has independent pastel text and background colours, with Markdown round-trip coverage for combinations. Pasted links stop extending into subsequent text. To-do items support page and web links, and their context menu can remove the to-do list. Browser spellchecking is disabled in the notebook. Existing groups are available when organizing notes. Page metadata and revision practice remain collapsed to give the canvas more room.

Resource dump replaces Inbox in navigation. It uses a three-column grid with nine items per page and an expanded detail view on selection. Links and attachment references in saved notes are indexed into the library without AI or automatic extraction. Existing bookmarks and files remain in the same local collection. Video thumbnail clicks select editable canvas cards; Play starts embedded playback separately, leaving object deletion and handles available.

Share includes account collaborators and a separate read-only snapshot link. Snapshot links work without recipient sign-in or the owner PC staying awake. They contain an explicitly created encrypted copy, expire after seven days and can be removed from the owner app. Later edits need a new link. Limits: ten active links per account, 2 MB of supported attached files, approximately 2.9 MB of plaintext snapshot content. Creating links requires Google sign-in. The full link contains the decryption key, so anyone receiving it can read the copy. Removing a link prevents new downloads; it cannot remove a copy someone already saved.

Slides exports a note, or up to ten selected notes from All notes, as a previewable portrait PDF for manual upload as a LinkedIn document post. Up to thirty slides are supported. Unused trailing canvas space is omitted. Exported slides preserve visual placement as images, so PDF text is not selectable and hyperlinks are not interactive. Review automatic page breaks and remote media previews before publishing. Nothing is posted to LinkedIn automatically.

Validation: 178 tests in 24 suites, app and relay TypeScript, production build, source-browser review of the grid and PDF generation, and live anonymous snapshot viewing and revocation through the deployed service. A downloaded PDF was checked and rendered with Poppler. Mouse zoom/pan, selection/deletion and rotated erasing have component/model coverage. Physical tablet stylus testing and native executable startup remain unverified. Automatic approval review previously blocked the native startup check. The installer remains unsigned.
