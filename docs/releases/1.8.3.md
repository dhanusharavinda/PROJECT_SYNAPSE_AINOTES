# Synapse 1.8.3

Focused but idle fields now release their editing lease. Leaving a field or backgrounding the app also releases an unused lease. Saves blocked by a genuinely active editor keep the local draft and retry automatically instead of showing the recovery panel. Conflicting edits still keep a recoverable draft. Snapshots identify the current editing session so a retained lease is not mistaken for somebody else's lock.

Links stay clickable with the Select cursor. Moving linked text uses its drag handle. Both Markdown page links and internal note URLs open inside Synapse.

Shared subpage links now resolve through the existing encrypted connection, with access checked by the owner's PC. Opening does not depend on the account index already listing a newly created child. Parent permissions also apply when a child has an older, separate collaborator list. Pages that are unrelated and not shared remain inaccessible. Missing or archived pages report an appropriate error.

Update both PCs through Help > Check for updates and restart. Refresh the tablet companion for the link interaction fix.

Validation: 230 automated checks, including automatic retry after a busy lease, idle release, inherited child permissions with separate collaborator lists, direct subpage resolution without an account index entry, and rejection of unrelated private pages. TypeScript, production build, installer packaging, and browser link checks were completed. Physical two-PC interaction and native EXE launch were not retested in this pass. Same-field simultaneous keystroke merging is not supported.
