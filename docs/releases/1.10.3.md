# Synapse 1.10.3

Creating a page from a slash command now keeps its link at the original writing position, including when the slash command was the only text in a placed box.

- Capture the originating text box or canvas position before the dialog opens.
- Insert once, without falling back to the main paragraph at the top.
- Stay on the parent page after creating and linking a child, so movement and Undo remain available.
- Keep the same behavior for shared notebooks.

Includes the PDF sharing and group selector fixes from1.10.2. Already misplaced text is preserved, not moved to a guessed location. Use the Write tool to select it and the movable-text action to turn it into a draggable box, or remove it with Backspace.
