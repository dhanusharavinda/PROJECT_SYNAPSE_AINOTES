# Synapse 1.2.1

- Empty writing areas no longer repeat instructions. A new note gets one short slash-link cue that disappears after five seconds.
- Removed bundled subject-specific starter notes and default topic text. Fresh notebooks start empty. Existing vault files are preserved.
- Copy and Delete are visible in the sheet toolbar when objects are selected. Right-clicking over writing keeps the whole-selection menu.
- Text Copy, Cut, and Paste are available in the context menu. The desktop app uses a narrow native clipboard bridge for reliable same-page editing.
- Pen marks render as smooth curves with a subtle speed-based width change. Coalesced input, dots, erasing, and undo remain supported.
- Pasting a YouTube link offers Link only, Named link, or Resizable thumbnail. The name field takes keyboard focus, Escape keeps the link, and timestamps are preserved. Select to drag a card; right-click to open or resize it.
- Theme and Book/Handwritten controls sit in the note toolbar. One theme control cycles Light, Dark, and Paper.
- Review cues and narration use readable text instead of HTML or annotation markers. Literal code is preserved for AI context. Previously saved scripts are cleaned for display and speech.

Automatic local saving remains enabled. The thumbnail option loads its image from YouTube and needs internet access; notes and layout still save locally. This Windows x64 installer is unsigned.
