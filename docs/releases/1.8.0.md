# Synapse 1.8.0

This update gives writing a quieter interface and moves learning exercises into Practice.

- Frame-coordinated Ctrl/Command scroll zoom, with a fixed canvas coordinate space and middle-button panning.
- Compact canvas tools. Arrow variations are symbols beneath the existing Arrow button.
- Contextual action wheel on desktop, with a touch-friendly action sheet on narrow screens. Categories reveal the actions for the current selection.
- Study lens dims other canvas objects. Red uncertainty pins help you find material to revisit.
- Practice includes selected-passage recall, diagram-label recall, contextual flashcards, hints, source passages and explicitly recorded attempts. Creating or opening a note does not record practice.
- Optional connection explanations appear in the knowledge graph and feed practice questions.
- Visual page history can recover selected text or individual canvas objects as copies. Main writing can be restored separately.
- AI diagrams choose a suitable flowchart, architecture, data flow, hierarchy, concept map or state machine. Selection is read with surrounding note context. Drafts require approval.
- AI requests have bounded context and output. Unchanged flashcards and recent diagram requests reuse cached results.
- Sharing separates People and View link, with additional details tucked away.
- A softly animated sage welcome fades into the notebook. A five-second version is optional in Settings. Reduced motion is respected.

Update from Help > Check for updates, or install the setup file from this release. Your existing vault stays in place.

## Practical limits

AI may still make mistakes, including incorrect connections. Review diagrams and card answers against the supplied source. Images and handwriting require text extraction before these text-based study tools can use them.

The standalone tablet app receives the shared canvas controls and launch treatment. AI Practice and visual history currently run in the main notebook workspace, with its local companion running. Physical stylus accuracy and native Windows launch need device testing; automated tests and browser checks cannot establish those.

History previews retain references to local assets. They cannot recover an attachment that has been removed from the vault itself.
