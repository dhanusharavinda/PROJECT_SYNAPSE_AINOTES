# Synapse 1.6.0

Add collaborators by Google account email. Shared pages open inside Synapse with viewer/editor permissions, live block and object presence, autosave, encrypted connections and local draft recovery. The owner PC must stay awake with Synapse open and internet connected. Adding account collaborators replaces older access links for that page.

Includes per-page themes with inherited defaults for subpages, a lighter dark palette, actual Markdown filename editing, more reliable selection of existing text and media, a separate paint bucket, and undo that preserves another person's newer canvas edits. Video thumbnails open an embedded player with an original-link fallback and stretch when resized.

Resource dump brings links, videos, posts, PDFs, images and supported uploads into one searchable library with bookmarks and reusable note attachments.

Google sign-in was verified through the live service and local app callback. An owner-only disposable page also passed an encrypted snapshot, editing lease and saved edit through the deployed account relay. The code passes 169 automated tests, app and relay TypeScript checks, and the production build. Two synthetic browser users demonstrated live editing and object presence. Physical multi-PC and tablet collaboration testing remain pending. The new account collaboration screen is currently in the Windows app, not the standalone tablet PWA. Google login accepts verified Gmail and Google Workspace accounts. Instagram playback may require opening the original post.

The Windows installer remains unsigned. Native executable startup testing was unavailable because the automatic approval review blocked that action; source server, browser, build and package checks were used instead.
