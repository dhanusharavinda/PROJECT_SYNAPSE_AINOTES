# Synapse 1.10.1

This update improves writing, page navigation and save recovery. It also includes the paged notebook and reviewed AI notes previously delivered in the local Windows build.

- Sheets above the old 1,500-object limit save without removing strokes. A quiet Next page prompt appears before a sheet gets heavy.
- Desktop and shared drafts survive reloads. Automatic retries preserve unacknowledged edits, and continuous writing no longer postpones saving indefinitely.
- Live ink draws without rebuilding the entire page on every pointer move. Long and interrupted strokes retain captured input.
- Page turns switch immediately. Optional curl previews are prepared while idle for smaller sheets.
- Zoom buttons, two-finger zoom, quick arrow styles, optional tool wheel and compact All tools menu.
- Fullscreen retains navigation to the parent note and note library.
- Import a local personal handwriting font for typed writing. Recognition and diagram reconstruction remain explicit, reviewed actions that preserve original ink, images and links.

Custom font import needs an existing TTF, OTF, WOFF or WOFF2 font. A single handwriting image does not train a complete alphabet. The font stays on the device where it was imported.

Physical pen pressure, palm rejection and remote-display latency depend on the device and connection. Browser and automated tests do not establish hardware latency guarantees.
