# Synapse 1.10.2

PDF export is available from the page toolbar, Share dialog and tablet notebook.

- Export all sheets, images, drawings, tables and accepted AI notes.
- Keep web links clickable, including links inside placed text and video previews.
- Include subpages and follow their links within the PDF.
- Wait for fonts and images before capture, and report image loading failures.
- Preserve overflow text from resized prose areas in export.

Use PDF, Prepare PDF, then Download PDF. On iPad, save the downloaded file to Files and share it from there. Video previews open the original website. Private attachment files and pages omitted from the export must be shared separately. Export preserves the visual layout as images with clickable link annotations, rather than editable or searchable document text.
