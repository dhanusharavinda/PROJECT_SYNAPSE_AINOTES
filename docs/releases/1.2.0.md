# Synapse 1.2.0

A quieter notebook with drawing and writing on the same page.

- Click blank space to write there, including beside an existing line. Enter continues on the next line.
- Ctrl+Z undoes drawing, erasing, and movement. Ctrl+Y or Ctrl+Shift+Z redoes. Normal text and input undo keep working.
- Pen dots, a partial-stroke eraser, more shapes, marquee selection, group movement, and whole-note copy/delete with undo.
- Right-click for formatting, resize, duplicate, layer order, and table actions. Selecting an object shows a small grip rather than another toolbar.
- Stable pixel coordinates and no selection toolbar shifting the page. Knowledge Graph positions now save correctly and survive refreshes.
- Tables resize horizontally and vertically. Clipboard paste distinguishes fresh external text from copied Synapse objects.
- One button cycles Light, Dark, and Paper. Paper rules follow the writing font baseline.
- All notes has search, group filters, sorting, dates, and multi-delete. Dates are optional and can be cleared.
- A searchable shortcut catalog covers drawing, formatting, files, navigation, and saving.
- Fixed code/drawing separators and raw variant markers in shared notes. Shared placed images retain file scoping.

Notes remain local in the existing vault. Complete placed layouts are saved in Markdown metadata. Object clipboard layout lasts within a running session; other applications receive text/Markdown. Erasing applies to pen strokes. Imported flowcharts are edited through Edit drawing. The notebook remains a page that grows downward, not an infinite drawing suite.

Windows x64. This build is unsigned. Install through Synapse's update bar or Help > Check for updates.
