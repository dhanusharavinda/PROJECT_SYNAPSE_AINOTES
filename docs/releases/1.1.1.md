# Synapse 1.1.1

Updates now appear inside the notebook when a new version is available. Choose Download update, follow the progress, then Restart and update. Synapse saves the current note before restarting and keeps the window open if saving fails. Choosing Later keeps your notebook open and does not install anything on exit.

This release also includes the 1.1 notebook sheet: draw directly on the page, arrange text and media freely, resize compact images and diagrams, and use Paper mode. Bulk deletion includes recoverable Trash, externally removed Markdown notes disappear from the list, and clipboard, PDFs, fonts, shortcuts, and context-menu scrolling are improved. Installed application files are about 40% smaller than version 1.0.

Your notes remain in your existing local vault. Updating replaces the app files. Keep normal backups of your vault.

If you use version 1.0 or 1.1, choose Help > Check for updates once. That version downloads the update in the background and offers Restart and update when ready. The in-app download bar is included after this update.

Windows x64. This build is unsigned. The GitHub release installer, block map, and latest.yml are published together for the desktop updater.
