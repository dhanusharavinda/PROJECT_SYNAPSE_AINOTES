# Synapse 1.8.2

Shared pages now listen for server changes through the encrypted relay. Incoming changes merge with pending edits to other objects, and continuous typing saves on a short cadence instead of waiting for typing to stop. Live presence uses the same event connection. Reconnection retries automatically and preserves local drafts.

Child and grandchild pages inherit their parent's collaborator role. Existing children are published to the shared account index when permissions are updated, and the index reconciles inherited access on startup and as new children are created. Revoking a parent removes inherited access. Unrelated linked pages keep their own access settings.

The action wheel starts at 208 pixels and expands to 292 only when a category opens. Touch screens retain an action sheet. Practice presents one passage at a time, excludes image filenames from recall material, and keeps the teacher's note picker in compact rows.

Install this update on both collaborating PCs through Help > Check for updates. Refresh or reopen the tablet web app for the interface changes. The PC hosting the shared notebook must remain online.

Validation: 224 automated checks, including two-session event delivery, presence, incoming edits while a local draft is pending, inherited permissions and revocation. TypeScript and production/installer builds verified. The editor protects each text area or object while another person edits it. It does not merge two people's simultaneous keystrokes within the same paragraph. Physical-device and native EXE launch were not retested in this pass.
