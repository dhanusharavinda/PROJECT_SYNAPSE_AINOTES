# Synapse 1.3.0

- Added **Dotted** as a fourth theme, with a quiet 16-pixel dot grid for visual alignment.
- Selected objects show drag and resize handles. Groups resize proportionally, including placed text and emojis. Added a permanent selection-delete icon beside Eraser.
- Added shape fills and fluorescent pink/green highlighter strokes. Saved ink colours stay unchanged across themes. Text colours now colour the letters rather than their background.
- Added paragraph alignment through slash commands and the right-click menu, and automatic list renumbering after edits.
- `/link`, `/page`, writing, tasks, and other common blocks appear first in the slash menu.
- Images have **Extract using AI** in their context menu. A local Ollama vision model or OpenAI can transcribe text and describe diagrams and approximate colours. Review/edit the draft before inserting; optionally rebuild an editable diagram from it. OCR remains available for text only.
- **AI teacher** in Review asks questions from selected notes, offers hints, and discusses your answer before you reveal the explanation.
- Diagram drafts can be corrected before acceptance. Labels and connection endpoints are editable, and invalid or disconnected diagrams are rejected. New diagrams and images use the movable sheet layout.
- Instagram post/reel links offer plain links, named links, and resizable preview cards. Public thumbnails are best effort; private or blocked posts fall back to the original link.
- Settings includes **Clear notebook data**, with typed confirmation and a recovery copy. Provider settings remain intact.

130 automated tests, packaged desktop checks, browser interaction checks, and live local vision/teacher/flowchart checks passed. AI image interpretation is approximate and requires review. Updates never replace your local vault. Windows x64, unsigned installer.
