# Synapse 1.4.0

Adds an installable iPad and Android notebook with offline pages, editable pen strokes, images and PDFs, local backups, and paired device sync with the Windows Markdown vault.

Pencil input uses hardware pressure when available, coalesced samples and frame-batched previews. Finger ink is available for capacitive styluses. Tablet canvas positions remain fixed when the viewport changes. Themes, selection, object handles and undo/redo use the existing notebook tools.

Private sync has a separate loopback gateway for Tailscale Serve, five-minute origin-bound pairing codes, persistent revocable tokens, idempotent uploads and conflict copies. Foreground sync runs about every two seconds when the PC is reachable. A browser app can be suspended in the background, so reopen it to resume syncing.

See docs/TABLET_APP.md for installation, pairing and backup instructions. The Windows build is unsigned. No physical iPad or Android stylus was available for hardware validation.

Validation: TypeScript, 139 automated tests, offline production-browser reopening, paired tablet-to-PC and PC-to-tablet transfer, phone-size writing/theme checks, and public HTTPS asset checks. Tablet installation caches about 2.7 MB of app files before user content.
